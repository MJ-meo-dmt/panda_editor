TERRAIN0

    
HEIGHTFIELD / GEOMIP LOD
Terrain System
Author Panda3D GeoMipTerrain heightfields with world scale, LOD, collision and runtime query support. Terrain remains an entity component, so hierarchy, scripts, signals and transforms continue to work normally.
Select or add a Terrain entity.

    
TERRAIN CONTEXT
Runtime API
entity.terrain_height(x, y)
entity.terrain_normal(x, y)
entity.terrain_configure(...)
entity.terrain_regenerate()
Sculpting
Editor-generated grayscale heightfields can be sculpted in the Level viewport with Raise, Lower, Smooth and Flatten brushes. Brush radius is authored in world units and each drag is undoable.
GeoMip LOD
Block size plus near/far distances control adaptive mesh detail. Bruteforce disables LOD for inspection or small terrains.
Collision
Optional static Bullet triangle-mesh collision is generated from the terrain geometry when Play starts.

TASKS / EVENTS0

    
MANAGED RUNTIME FLOW
Tasks / Events
Author pause-aware timers and named custom events without hand-writing update-loop timers. Tasks feed the existing script on_event() and Signals 2.0 systems.
Select an entity with a Tasks / Events component.

    
RUNTIME API
How timers execute
Runtime-created task_every() timers start immediately. Event-style timers arrive in on_event(). Direct method timers use method="..." and call method(self, entity, world, payload).
Managed timers
world.call_later()
world.task_every()
world.task_cancel()
world.task_info()
entity.task_start() (authored tasks)
Runnable example
Open the light-flicker script to see a repeating direct method callback changing live light intensity and range.
Custom events
world.event_send()
entity.event_send()
Authored hooks route named Panda messenger events into script events and optional Signals 2.0 outputs.
